# C - Hello, World

- `0-preprocessor`: runs a C file (name in $CFILE) through the preprocessor and saves the result in the file c.
- `1-compiler`: compiles a C file (name in $CFILE) without linking, producing the .o file with the same base name.
- `2-assembler`: generates the assembly code of a C file (name in $CFILE) and saves it in the .s file with the same base name.
- `3-name`: compiles a C file (name in $CFILE) and creates an executable named cisfun.
- `4-puts.c`: C program that prints "Programming is like building a multilingual puzzle using puts.
